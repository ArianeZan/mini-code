## Documentation Policy

Documentation follows the shipped system, not only the roadmap.

- Every milestone updates the README status and affected guides.
- Planned behavior is labeled as planned.
- Commands are verified against the repository scripts.
- Security limits and accepted risks are documented with the implementation.
- Architecture decisions are recorded near the technical context they affect.
